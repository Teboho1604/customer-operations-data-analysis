# Customer Service Data Quality & Analysis

## Project Overview

This project analyses a customer-service dataset to demonstrate a complete data analytics workflow.

The project focuses on:

- Data quality
- Data cleaning
- Data validation
- Exploratory data analysis
- SQL analysis
- Python analysis
- Data visualisation
- Business-focused findings

The dataset contains 300 customer-service records covering customer issues, communication channels, resolution times, satisfaction scores and repeat contacts.

This is a synthetic portfolio dataset created for analytical practice and demonstration.

---

## Business Questions

The analysis investigates questions such as:

1. Which issue types generate the highest number of customer cases?
2. Which issue types take the longest to resolve?
3. Which issue types have lower customer satisfaction?
4. Which communication channels have higher repeat-contact rates?
5. How does resolution time vary across channels?
6. How does customer satisfaction change over time?
7. Is there a relationship between resolution time and satisfaction?
8. How does repeat contact relate to customer satisfaction?
